# 公募基金昨日收益排行 — fund_rank.py

链接国内公募基金行情，查询**昨日收益排名前十**的开放式公募基金。

## 数据源

天天基金网（东方财富）开放式基金排行接口：

```
http://fund.eastmoney.com/data/rankhandler.aspx?op=ph&dt=kf&ft=all&sc=rzdf&st=desc&pi=1&pn=10
```

- `sc=rzdf` 按**日增长率**（日涨跌幅）排序 —— 即“昨日收益”
- `st=desc` 降序（收益榜）；`st=asc` 升序（跌幅榜）
- `dt=kf` 开放式基金；`ft` 基金类型（all/gp/hh/zq/zs/qdii/fof）

“昨日收益”= 最近一个净值日期的日增长率。基金净值通常在交易日收盘后
（约 19:00–21:00）更新，脚本会打印实际**净值日期**供核对。

## 用法

```bash
python3 fund_rank.py               # 全部公募基金，昨日日增长率前十
python3 fund_rank.py --top 20      # 前 20 名
python3 fund_rank.py --type gp     # 仅股票型
python3 fund_rank.py --asc         # 跌幅榜（升序）
python3 fund_rank.py --save        # 同时保存 JSON 到 output/
```

## ⚠️ 网络要求

接口域名为 `fund.eastmoney.com`。若运行环境的出口策略未放行
`*.eastmoney.com`（例如 Claude Code on the web 的受限沙箱），脚本会以
`exit 2` 输出“网络受限”提示，而不会报错或编造数据。请在可访问该域名的
环境中运行，或在环境的网络出口设置中放行 `fund.eastmoney.com`。

> 数据准确性遵循 `DATA_VERIFICATION_SKILL.md`：净值/涨跌幅以净值日期为准，
> 发布前应复核。
